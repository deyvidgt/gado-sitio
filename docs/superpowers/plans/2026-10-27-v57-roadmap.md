# v5.7 Roadmap — Melhorias UI/UX e Mobile Refinements

**Status:** Planejamento  
**Prioridade:** Alta  
**Estimativa:** 3-4 sprints

---

## 🎯 Objetivo Geral

Refinar a experiência mobile de v5.6, melhorar responsividade, adicionar dark mode, e otimizar performance em redes lentas (4G/3G).

---

## 📱 Eixo 1: Mobile-First Refinements

### 1.1 Drawer/Menu Hamburger
- [ ] Menu colapsável no topo (mobile ≤480px)
- [ ] Navegação por abas sticky ao scroll
- [ ] Swipe para voltar (Android/iOS)

### 1.2 Bottom Action Bar
- [ ] Ações contextuais flutuam no rodapé (mobile)
- [ ] Desaparecem ao scroll down, reaparcem ao scroll up
- [ ] Exemplo: formulário de pesagem com [Pesar] [Cancelar] fixo

### 1.3 Teclado Virtual
- [ ] Input type="number" com teclado numérico
- [ ] Input type="tel" para brincos (0-99)
- [ ] Emoji picker para observações (mobile)

### 1.4 Gestos
- [ ] Swipe left/right para abas (animal → próximo/anterior)
- [ ] Swipe up para expandir card (ficha mobile)
- [ ] Long-press para menu de contexto

---

## 🌗 Eixo 2: Dark Mode

### 2.1 CSS Variables
- [ ] Definir paleta de cores em `:root`
- [ ] `prefers-color-scheme: dark` + toggle manual
- [ ] Persistir preferência em `localStorage`

### 2.2 Componentes
- [ ] Atualizar `.card`, `.metric`, `.badge`, `.barra` para dark
- [ ] Gráficos (Chart.js) com tema escuro automático
- [ ] Imagens com `filter: invert` opcional (fotos de animal não)

### 2.3 Testes
- [ ] Screenshots em light e dark
- [ ] Contraste mínimo WCAG AA em ambos

---

## ⚡ Eixo 3: Performance & Offline

### 3.1 Lazy Loading
- [ ] Imagens com `loading="lazy"` (fotos de animal)
- [ ] Carregamento paginado de histórico (últimas 50 registros)
- [ ] Virtual scroll em listas grandes (>100 itens)

### 3.2 Service Worker Melhorado
- [ ] Cache inteligente (estática: 30 dias, dados: 1 dia)
- [ ] Prefetch de rotas visitadas frequentemente
- [ ] Fallback offline com página "Sem conexão"

### 3.3 Bundle Size
- [ ] Remover Chart.js inline se pequeno, carregar via CDN
- [ ] Tree-shake CSS não usado (`unused: true` em build)
- [ ] Minify HTML/CSS/JS em produção

---

## 🎨 Eixo 4: Componentes & Design System

### 4.1 Modais
- [ ] Modal reutilizável (confirmação, detalhe, erro)
- [ ] Backdrop que fecha ao clicar fora
- [ ] Animation fade-in/out suave

### 4.2 Notificações (Toast)
- [ ] Toast para ações (salvar, deletar, sucesso)
- [ ] Posição fixo (top-right desktop, bottom mobile)
- [ ] Auto-dismiss após 3s ou manual

### 4.3 Loading States
- [ ] Skeleton screens em lugar de "Carregando..."
- [ ] Spinner animado com mensagem contextual
- [ ] Disable de botão + cursor:wait ao enviar

### 4.4 Formulários
- [ ] Campo flutuante (label sobe ao focar)
- [ ] Validação em tempo real (vermelho/verde)
- [ ] Helper text (dica) abaixo do campo
- [ ] Carrossel de erros (foco no primeiro erro)

---

## 📊 Eixo 5: Acessibilidade (WCAG 2.1 AA)

### 5.1 Navegação por Teclado
- [ ] Tab order correto (atalho Tab → próximo input)
- [ ] Enter em button = click
- [ ] Escape fecha modal/dropdown
- [ ] Skip link "Pular para conteúdo" (logo no topo)

### 5.2 Screen Reader
- [ ] `aria-label` em ícones (botões sem texto)
- [ ] `aria-live="polite"` em alertas
- [ ] `aria-expanded` em menus/dropdowns
- [ ] Semântica HTML (`<button>` vs `<div>`, etc)

### 5.3 Contraste & Fontes
- [ ] Fonte ≥16px mobile (ou zoom readable)
- [ ] Contraste ≥4.5:1 para texto normal
- [ ] Espaçamento entre elementos ≥44x44px (touch targets)

---

## 🐛 Eixo 6: Melhorias de UX Descobertas em v5.6

### 6.1 Dashboard
- [ ] Card de clima: mostrar próximo evento (parto, vacinação)
- [ ] Cards minimizáveis (expand/collapse)
- [ ] Reordenação customizável (arrastar cards)

### 6.2 Calendário
- [ ] Mini-calendário de navegação (lateral esquerda)
- [ ] Exportar mês como PDF ou ICS
- [ ] Sincronizar com Google Calendar (opcional)

### 6.3 Comparativo
- [ ] Adicionar ranking (1º, 2º, 3º melhor)
- [ ] Exportar tabela como CSV/Excel
- [ ] Filtro por categoria (lactação, corte, etc)

### 6.4 Busca
- [ ] Histórico de buscas recentes (últimas 5)
- [ ] Busca avançada (por intervalo de datas, tipo)
- [ ] Sugestões inteligentes (autocomplete por padrão)
