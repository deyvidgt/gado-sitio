ROTAS PRINCIPAIS (app.py)
================================================

  GET  /                          → dashboard
  GET  /lista?aba=Compras         → listagem de registros
  POST /compra/nova               → salvar nova compra
  POST /gasto/novo                → salvar novo gasto
  POST /venda/nova                → salvar nova venda
  POST /manejo/novo               → salvar manejo
  GET  /visitas                   → histórico de visitas
  POST /visitas/nova              → registrar nova visita
  GET  /relatorios                → página de relatórios
  GET  /relatorio-pdf             → baixar PDF do relatório
  GET  /exportar                  → baixar Excel formatado
  GET  /configuracoes             → gerenciar usuários
  GET  /api/fluxo                 → JSON fluxo de caixa (gráfico)
  GET  /api/membros               → JSON resultado por membro (gráfico)
  GET  /api/chuvas                → JSON chuvas mensais (gráfico)
  GET  /api/cotacao-imea          → cotação boi gordo (IMEA/Playwright)
  GET  /api/cotacao-scot          → cotação novilha (Scot Consultoria)

INDICADORES FINANCEIROS (calculos.py)
================================================

  CMP   = Custo Médio Ponderado por cabeça
          = Σ(valor_compra) / Σ(qtd_compra)

  GPCab = Gasto acumulado por cabeça
          = Σ(valor_gasto / estoque_na_data_do_gasto)

  CTCab = Custo Total por cabeça = CMP + GPCab

  Break-even = capital_imobilizado / estoque_atual
               (preço mínimo por cabeça para recuperar o capital)

  Resultado realizado = receita_vendas − custo_histórico_vendidos
  ROI realizado       = resultado_realizado / custo_vendidos × 100

================================================
SENHAS E SEGURANÇA
================================================

  Arquivo de senhas : usuarios.json (na pasta do programa)
  Formato           : bcrypt (após primeiro login) ou SHA-256 (legado)
  Senha padrão      : sitio2025
  Sessão            : 8 horas (configurável em config.py → SESSAO_MINUTOS)
  Proteção CSRF     : token automático em todos os formulários POST
  Secret key        : variável de ambiente GADO_SECRET_KEY
                      (se não definida, usa valor padrão — só para desenvolvimento)

  Para gerar secret key segura:
    python -c "import secrets; print(secrets.token_hex(32))"
