Política de Privacidade

Sítio Santo Antonio — sistema de gestão de gado · última atualização: 16/10/2026

Este é um sistema particular de uma família, usado só pelos membros cadastrados (Geane, Deyvid e Nilson) para controlar o rebanho do Sítio Santo Antonio. Não é aberto ao público e não há cadastro de usuários externos.

Quais dados o sistema guarda

  • Registros do rebanho: compras, gastos, vendas, manejo, visitas e cadastro dos animais.
  • Fotos dos animais tiradas pelos membros, com data, tipo, legenda e o nome de quem enviou.
  • Nome de usuário e senha (guardada só como código protegido, nunca em texto) de cada membro.

Uso do Google Drive

O sistema usa a API do Google Drive, autorizada uma única vez pela conta dona da pasta da família, exclusivamente para:

  • criar subpastas por animal e salvar as fotos dentro da pasta do sítio;
  • ler essas fotos para mostrá-las aos membros logados;
  • mandar para a lixeira do Drive uma foto que um membro excluir.

O sistema não lê, não altera e não apaga nenhum outro arquivo do Drive, não acessa e-mails, contatos ou qualquer outro dado da conta Google. As fotos ficam privadas: só são exibidas a quem está logado no sistema e nunca são compartilhadas publicamente.

Compartilhamento

Nenhum dado é vendido, cedido ou compartilhado com terceiros, nem usado para publicidade. Os dados ficam no servidor do sistema (PythonAnywhere) e no Google Drive da família.

Como revogar o acesso

A conta Google pode remover a autorização a qualquer momento em myaccount.google.com/permissions. Depois disso o sistema para de enviar fotos; as que já estão no Drive continuam na pasta da família.
